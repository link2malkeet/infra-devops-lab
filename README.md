# Infra / DevOps Lab

## Purpose
This repository is a long-running DevOps and Infrastructure learning lab.
It simulates a real production system that evolves over time.

## Goals
- Learn infrastructure, DevOps, and SRE practices deeply
- Build systems, not tutorials
- Practice safe changes, failures, and recovery
- Document decisions and incidents

## Non-Goals
- Shallow tool collection
- Copy-paste learning
- Perfect code from day one

## How this repo is used
Every change follows this cycle:
1. Design
2. Build
3. Break
4. Fix
5. Document

Failures are intentional and documented.
